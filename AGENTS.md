# ЗаказПоток

Лендинг и шоукейс CRM для производителей и монтажников. Начни с `README.md`.

## Где работать

- `index.html`, `site/style.css`, `site/app.js` — текущий лендинг. `site/` содержит изображения, шрифты, видео и документацию активной версии.
- `crm/` — локальный CRM-прототип. Кнопка «Смотреть CRM» на лендинге ведёт к видеошоукейсу, описанному в `README.md`.
- `motion/` — композиция Remotion. В локальной рабочей папке `archive/`, `landings/` и `concept-c/` содержат сохранённые варианты, `outputs/` содержит собранные материалы.

## Запуск и проверка

- Из корня запусти `python3 -m http.server 4173 --bind 127.0.0.1`, затем открой `http://127.0.0.1:4173/`.
- Для лендинга сборка не требуется. После правок проверь мобильную ширину, согласованную композицию первого экрана, вызов и воспроизведение шоукейса и CTA в MAX.
- Для пересборки видео выполни `npm ci` и `npm run render` в `motion/`. Проверь ролик и обложку в `site/video/`.
- Для упаковки или публикации следуй разделу «Публикация» в `README.md`. Сохраняй относительные пути и проверяй архив на размещение в подпапке.

## Ограничения

- Для правок интерфейса сначала открой `site/docs/DESIGN-SYSTEM.md`. Для проверки UI открой `site/docs/UI-POLISH.md`.
- Сохраняй текущую фотографическую композицию и согласованные CTA при точечных правках. Формулируй сценарии и возможности согласно фактически показанной версии CRM.
- Для кросс-проектных задач открой `~/Home/projects/MAP.md`, если Home доступен.
