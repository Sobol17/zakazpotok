# ЗаказПоток — лендинг с шоукейсом

Итоговая страница — `index.html`; ресурсы — `site/`. Сборка и установка зависимостей не нужны.

Локальный просмотр: http://127.0.0.1:4173/

Если сервер выключен, из папки проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

## Текущая версия

Фотографический лендинг для производителей и монтажников ворот и металлоизделий. Восстановлена выбранная композиция: мастерская на весь первый экран, заголовок «Заказы и оплаты / в одной системе» с курсивной второй строкой и две кнопки. Геометрия hero сохранена из `archive/editorial-video-landing.zip`.

Под описанием CRM рядом с кнопкой «Обсудить пилот в MAX» расположена основная кнопка «Смотреть CRM». Далее идут четыре этапа **заявка → замер → оценка → выполнение** в единой полосе с пиктограммами, фотография металла с примером расчёта остатка, условия пилота, два ответа и деловой футер. В этой композиции уменьшены заголовки разделов, внутренние и межсекционные отступы. Интерактивное демо CRM открывается отдельно по адресу `/crm/`. В тексте названы откатные ворота, ограждения, навесы и металлоизделия; также обозначено соответствие другим командам с таким же процессом.

## Шоукейс и авторский разбор

Под плеером доступно раскрываемое текстовое описание действий и сумм. По кнопке «Смотреть CRM» на первом экране открывается 22-секундный ролик. В нём открывают заказ № 1045, проверяют смету, записывают оплату и находят её в разделе «Оплаты». Первый кадр совпадает с обложкой. Крупные планы сметы и оплаты сопровождаются суммами и шкалой этапов. В стереодорожке мягкие звуковые акценты совпадают с кликами. Видео запускается по нажатию, со встроенными контролами браузера и поддержкой воспроизведения на странице на телефоне.

Файл для лендинга — `site/video/overview.mp4`, обложка — `site/video/overview-poster.jpg`. Композиция Remotion и снимки демоэкранов находятся в `motion/`. Для пересборки выполните в этой папке `npm ci`, затем `npm run render`. Можно указать путь к локальному Chrome переменной `REMOTION_BROWSER_EXECUTABLE`.

После четырёх этапов, перед пилотом, расположен раздел `#demo`. Пока запись готовится, здесь показан пример оплаты демозаказа № 1045. Для подключения записи укажите в `data-video-src` раздела путь к MP4. При наличии обложки добавьте `data-poster`. На месте фотографии появится полноразмерный плеер авторского разбора. При упаковке добавьте запись и её обложку в архив вместе с остальными ресурсами.

## Публикация

Лендинг опубликован на [zakazpotok.ru](https://zakazpotok.ru/), интерактивное демо CRM — на [zakazpotok.ru/crm/](https://zakazpotok.ru/crm/). Для `заказпоток.рф` и вариантов с `www` Caddy настроен на перенаправление к основному домену с сохранением пути и параметров запроса.

Оба приложения раздаёт действующий Caddy проекта Financer на VPS. В контейнере корень сайта — `/data/zakazpotok/current/out`. Символьная ссылка `current` указывает на каталог в `/data/zakazpotok/releases/`. Чтобы обновить сайт, подготовьте новый каталог релиза, поместите лендинг с ресурсами в `out/`, а результат `npm run build` из `crm/` — в `out/crm/`. После проверки файлов атомарно переключите `current`. Для отката переключите ссылку на предыдущий релиз. Конфигурация доменов находится в `/var/www/financer/Caddyfile` на хосте.

Соберите архив лендинга из корня проекта. Пути относительные и поддерживают размещение в подпапке.

```sh
mkdir -p outputs
zip -FS -r outputs/zakazpotok-landing.zip index.html README.md privacy consent cookies site -x 'site/vendor/*' '*.DS_Store'
```

Распакуйте содержимое в корень статического хостинга.

Вместе с лендингом публикуются `privacy/`, `consent/` и `cookies/`, а также PDF коммерческого предложения в `site/documents/`. В футере указаны реквизиты ИП, почта, телефон и MAX. Баннер записывает технический cookie при явном разрешении и хранит отказ в браузере. Изменить выбор можно в футере. Сайт не подключает аналитику и рекламу.
