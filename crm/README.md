# Демо CRM ЗаказПоток

React, Ant Design и Vite. 26 заказов, пять сотрудников и история оплат за 90 дней. У 16 исторических заказов есть аванс и окончательный расчёт. Браузер сохраняет заявки, фотографии, расчёты и выплаты в localStorage для текущего адреса. Кнопка «Сбросить демо» восстанавливает примеры с датами относительно дня сброса.

## Запуск

Из папки crm выполните `npm ci` и `npm run dev`. Для статического хостинга выполните `npm run build` и разместите содержимое папки dist. Страницы открываются по хеш-ссылкам и поддерживают размещение в подпапке. Для проверки расчётов выполните `npm test`.

## Сценарий показа

1. В реестре откройте «Новую заявку», укажите клиента, изделие и адрес.
2. Назначьте замер. Внесите ширину и высоту, при необходимости добавьте фото. Завершение замера начислит замерщику 1 000 ₽.
3. В смете добавьте материалы и работы. Согласуйте стоимость и внесите аванс через «Принять оплату». Остаток сразу виден в карточке и в разделе «Оплаты».
4. Завершите изготовление и выберите монтажников. Мастеру цеха начислится 6 000 ₽. При сдаче заказа 4 000 ₽ распределятся поровну между участниками бригады.
5. Откройте сотрудника, сверьте начисления по заказам и запишите выплату. Календарь показывает активные этапы на выбранный день.
